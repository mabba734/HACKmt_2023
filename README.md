# HACKmt 2023 — Unity UI Interaction Prototype

This project was created during HACKmt 2023, a 36-hour hackathon at Middle Tennessee State University. Our team built an interactive Unity prototype focused on UI controls, variable adjustment, and smooth visual feedback.

The goal was to quickly build a working demo that explored user interaction through dynamic sliders, fading UI elements, and simple state management.

## Project Overview

The prototype includes:
- A Unity scene with lighting, camera, and basic environment setup
- A custom slider-based UI that allows users to adjust different variables
- Smooth fade-in and fade-out animations for UI elements using C# coroutines
- A system for storing and recalling slider values based on button IDs
- Console logging for real-time visibility of variable changes

This project was built rapidly during the hackathon, prioritizing functionality and interaction over full game mechanics.

## Key Features

- Slider that appears on button press and fades out when inactive
- Stored values for each variable using a dictionary keyed by string IDs
- Smooth UI transitions for knob, fill area, and line graphics
- Auto-hide behavior that fades UI after a delay
- Clean and minimal Unity scene for prototyping

## Technologies Used

- Unity 2021.3.17f1
- C# scripting
- UnityEngine.UI
- Coroutines for animation and timing
- Git and GitHub for source control
